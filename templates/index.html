HOW THE AI WORKS

1
INPUT FEATURES

The model receives three student performance features: Study Hours, Attendance, and Previous Marks.

2
TRAINING-FITTED STANDARDIZATION

The same StandardScaler fitted strictly on training data (mean & variance) is applied during inference.

3
DENSE LAYERS (8 + 4 Neurons + ReLU)

Two hidden Dense layers with non-linear ReLU activations compute latent representation vectors.

4
OUTPUT LAYER (1 Neuron + Sigmoid)

The output neuron produces a calibrated continuous pass probability in [0.0, 1.0].

5
0.50 THRESHOLD → PASS / FAIL

A decision threshold of 0.50 converts that probability into final outcome: PASS or FAIL.

LIMITATIONS & RESPONSIBLE USE

  • Dataset is synthetic: The model was trained and evaluated on synthetic educational records designed for demonstration and learning.
  • Feature scope: The model uses only three features (Study Hours, Attendance, Previous Marks) and cannot account for socioeconomic, health, or institutional factors.
  • Probabilistic predictions: Predictions represent model probability estimates under a 0.50 threshold, not definitive certainties.
  • No automated decisions: This tool should not be used as the sole basis for high-stakes academic decisions, grading, or disciplinary actions.
  • Generalization disclaimer: Performance on synthetic data does not guarantee equivalent performance on real-world student populations.
  • Interpretation: Predictions should always be interpreted as machine learning outputs requiring human academic oversight.
